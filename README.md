# Calma — launcher minimalista anti-distracciones

- Pantalla principal: hora, fecha y hasta 6 apps fijadas (solo texto).
- Desliza hacia arriba: lista de apps A–Z sin iconos, con buscador.
- Mantén pulsada una app: fijar, pausa consciente, ocultar, info, desinstalar.
- Mantén pulsada la hora: apps ocultas, duración de la pausa, launcher predeterminado.
- Pausa consciente: antes de abrir esa app aparece una cuenta atrás y cuántas veces la abriste hoy.

## Cómo instalarlo
**Opción A – Android Studio:** File > Open (esta carpeta) > Run en tu móvil (o Build > Build APK).
**Opción B – GitHub:** sube la carpeta a un repo, pestaña Actions > "Compilar APK" > Run workflow. Descarga `calma-apk`.

Después pulsa Home y elige "Calma" > Siempre.
