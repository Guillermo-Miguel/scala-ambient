# Scala Ambient

Sistema de infoentretenimiento y luz ambiente para un Škoda Scala (2019).

- `android/` — app para el móvil (Inicio, Navegación, Música, Teléfono, Luz ambiente, Ajustes) con módulo para Android Auto.
- `firmware/ScalaAmbient/` — firmware del ESP32 que controla las tiras LED.

Cada vez que se sube un cambio, GitHub compila la APK y la publica en **Releases**.
